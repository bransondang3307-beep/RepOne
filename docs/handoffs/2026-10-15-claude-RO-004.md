## Objective
Make Claude Code, Codex, Gemini and ChatGPT work from the same instructions, progress tracker and
task assignments, with a standard handoff and PR workflow. No Sprint 2 work, no code or algorithm changes.

## What changed
- **Shared instructions:** `AGENTS.md` rewritten as the canonical file (original three paragraphs kept
  verbatim) — reading order, precedence, roles, 9-step sync workflow, status vocabulary, protection rules.
  `CLAUDE.md` and `GEMINI.md` import it with `@` and add only tool-specific notes.
  `docs/agents/CHATGPT.md` holds paste-in Project instructions for ChatGPT (it cannot load repo files itself).
- **Tracker:** `PROJECT_STATUS.md` — verified-on-`main` table with evidence, open branches, active
  milestone, blockers, next steps, change log.
- **Task board:** `TASKS.md` — RO-001…RO-018 with owner, priority, status, dependencies, branch/PR,
  completion criteria. Milestones 2–5 of the Sprint 1 alignment plan are listed but **not started**.
- **Handoffs:** `docs/handoffs/README.md` (naming, rules, index) and `TEMPLATE.md`.
- **PR template:** `.github/pull_request_template.md` mirrors the handoff and the safety checklist.
- **CI:** `.github/workflows/ci.yml` — `npm ci`, boundary check (`--if-present`), typecheck, tests on
  every PR and on `main`; `handoff` job fails a PR that adds no dated handoff (opt-out: `[no-handoff]`).
- **ADR 0004** records the workflow (0003 is taken on the unmerged `sprint-1-alignment` branch).

## Known limitations / risks
- Branch protection is unavailable on this private repo's GitHub plan, so "PR + review before merge" is a
  convention; CI reports but cannot block merges.
- `@` imports in `GEMINI.md` depend on the Gemini CLI's import support; the file also tells Gemini to read
  `AGENTS.md` directly if imports are unsupported. Not tested with Gemini itself.
- ChatGPT synchronization is manual (paste-in instructions + GitHub connector read access); not tested.
- Concurrent edits to `TASKS.md` by several agents can conflict; mitigated by "edit only your row".
