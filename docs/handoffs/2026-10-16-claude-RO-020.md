## Objective
"RepOne" is a temporary name. Make all future work rebrandable: centralise user-facing product names, avoid
hardcoded branding, keep core functionality brand-free, and rename no existing identifiers or paths.

## What changed

  (`CLAUDE.md` / `GEMINI.md` import `AGENTS.md`; ChatGPT's instructions point to it).

  (display branding / technical identifiers / core functionality), where the single brand configuration lives,
  rules for wire formats and devices, a CI guard, and how a later rename would be done.
- No code, identifiers, package names, paths or the repository were renamed or changed.
