## Objective

Reduce PR coordination work while preserving owner control, $0 additional AI API spend, and the RO-019 policy.

## What changed

- `.github/workflows/pr-tracking.yml` runs a read-only PR handoff report and its tests.
- `scripts/pr-handoff.mjs` validates GitHub event metadata and writes the summary. `scripts/pr-handoff.test.mjs` covers draft and fork states, head changes, malformed metadata, hostile input and the entry point.
- `docs/automation/level-3.md` records the design, pilot, security review, owner gate and bounded subscription fix procedure. The RO-019 runbook links to it and the PR template asks for review evidence.
- Task and project status changes follow the normal task-board and post-merge processes. Several active PRs already edit `TASKS.md`.

## Decisions and limitations

- ADR 0005 remains the cost and credential policy. The workflow reports event state and has no PR mutation or agent dispatch capability.
- GitHub reported `main` as unprotected with no active rules on 2026-11-08. Repository settings are an owner decision before accepting the pilot.
- The PR summary is advisory. Review quality, fix authorization and the round cap require a maintainer.
