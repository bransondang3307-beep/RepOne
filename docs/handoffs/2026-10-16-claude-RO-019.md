## Objective
Let Claude Code and Codex exchange review findings and fixes through GitHub automatically using the official
`anthropics/claude-code-action` and `openai/codex-action`, with at most two fix rounds, no automatic merges,
least privilege, secrets only in Actions secrets and a manual testing mode — without enabling paid calls.

## What changed
- **`.github/workflows/ai-codex-review.yml`** — gate → verify (`npm ci && npm run verify`, no secrets) → Codex
  (`codex-action` v1.13 pinned, `:read-only` profile, `drop-sudo`, last step, structured output schema) → post
  (sanitised review comment with bot marker, labels, next-step decision, dispatch of the fix workflow).
- **`.github/workflows/ai-claude-fix.yml`** — gate (re-validates the review comment: bot-authored, same PR, current
  head SHA, round cap, not already attempted) → Claude (`claude-code-action` v1.0.248 pinned; file tools only, no
  Bash/web; PR copy without `.git`; PR agent config moved away; read-only token) → verify-fix (overlay onto a
  pristine checkout, patch policy, handoff record, `npm ci && npm run verify`; no secrets) → push (contents:write
  only, no PR code, fast-forward to the `claude/*` branch, refuses default/unprefixed branches) → report.
- **`.github/ai-loop/`** — config (caps, labels, protected paths), pure library, gates, posting/reporting
  modules, CLI, prompts, Codex output schema, dry-run fixture, and **62 tests**.
- **`.github/workflows/ci.yml`** — `workflow_dispatch` trigger (so the loop can run CI on bot commits) and a step
  running the loop tests. No other CI behaviour changed.
- **Docs:** `docs/automation/claude-codex-loop.md` (setup, credentials, permissions, costs, test plan),
  ADR 0005, `AGENTS.md` §1 item 7 + new §5 (former §5 "Rules" renumbered §6), `CLAUDE.md` note, `TASKS.md` RO-019 row/details (next ID RO-020).
- **Not changed:** application code, tests, the rep-counting algorithm, `PROJECT_STATUS.md` (status PR after merge).

## Decisions / ADRs
- ADR 0005 (Proposed → Accepted on merge). Default Claude model `claude-opus-5-5` (override with

## Known limitations / risks
- First real runs on GitHub may expose integration issues (action behaviour on `workflow_dispatch`, artifact
  hand-offs, Codex output size); follow the staged test plan.
- Codex pricing/default model could not be confirmed from primary sources in this session — pin `CODEX_MODEL`
  and check OpenAI pricing before enabling.
- Merge approval is procedural (no branch protection on GitHub Free private repos); no merge path exists in the loop.
- Write-access users can alter workflows in their own PR branches (GitHub's trust boundary); automatic runs skip
  PRs touching automation files.
- `docs/handoffs/README.md` index not updated here because open PR #2 edits the same lines; will be added in the
  status-update PR.
